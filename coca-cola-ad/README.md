# Новогодний рекламный ролик Coca-Cola (15 сек)

Готовое видео: **`coca_cola_new_year_ad.mp4`** — 1920×1080, 25 fps, H.264 + AAC стерео, 15 секунд.

## Раскадровка

| Время | Сцена |
|---|---|
| 0–5 c | Ночь, падает снег. Камера медленно подъезжает к холодной стеклянной бутылке Coca-Cola в сугробе. Рядом — ёлочные шары, позади — размытые огни ёлок и гирлянд. |
| 5–10 c | Макро-план: камера скользит вверх по бутылке. Видны капли конденсата, этикетка и пузырьки газа в напитке. Звучит «пш-ш-ш» открывающейся бутылки. |
| 10–15 c | Камера отъезжает, бутылка остаётся слева. Появляются надписи «ПРАЗДНИК К НАМ ПРИХОДИТ», «Coca-Cola» и «С Новым годом!». |

Музыка — аранжировка «Jingle Bells» (общественное достояние) в стиле музыкальной шкатулки, с бубенцами, пэдом и звуковыми эффектами.

## Как это сделано

Ролик полностью процедурный, без стоков и без нейросетевой генерации:

- `scene.html` — 3D-сцена на GLSL (WebGL2, ray marching). В ней:
  - бутылка с преломлением света в стекле и колу с поглощением света;
  - капли конденсата, работающие как линзы, и пузырьки газа;
  - снег с блёстками и ёлочные шары;
  - огни в боке и падающий снег.
  
  Постобработка: глубина резкости (DoF), bloom, тональная компрессия ACES, цветокоррекция, зерно.
- `render.js` — рендерит кадры в headless Chromium (Playwright).
- `audio.py` — синтезирует саундтрек на NumPy.
- `build.sh` — запускает весь конвейер: кадры → звук → `ffmpeg` → mp4.

Пересобрать ролик: `./build.sh`. Нужны Node + Playwright, Python 3 + NumPy и ffmpeg. Рендер на CPU через SwiftShader занимает около 2 часов.

> Некоммерческий фан-концепт. Coca-Cola — товарный знак The Coca-Cola Company. Логотип нарисован обычным шрифтом и не воспроизводит фирменный.
